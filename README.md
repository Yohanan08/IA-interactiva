# IA Interactiva

IA Interactiva es una aplicación web que permite interactuar con un asistente de inteligencia artificial a través de texto.  
La aplicación está diseñada para ofrecer respuestas rápidas y generar contenido utilizando modelos de IA.

## Demo

https://ia-interactiva.vercel.app/

## Descripción

Este proyecto consiste en una interfaz web que permite al usuario comunicarse con un asistente de inteligencia artificial.  
El sistema procesa las preguntas del usuario y genera respuestas en tiempo real, ofreciendo una experiencia interactiva similar a un chat.

La aplicación está pensada como una demostración práctica de integración de inteligencia artificial en aplicaciones web modernas.

## Características

- Interfaz de chat interactiva
- Comunicación con modelos de inteligencia artificial
- Respuestas generadas en tiempo real
- Interfaz simple y fácil de usar
- Aplicación desplegada en la nube

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- API de inteligencia artificial
- Deploy en Vercel

## Cómo usar la aplicación

1. Escribe una pregunta o mensaje en el campo de texto.
2. Envía tu mensaje.
3. La inteligencia artificial procesará la solicitud.
4. Recibirás una respuesta generada automáticamente.

## Objetivo del proyecto

El objetivo de este proyecto es explorar la integración de inteligencia artificial en aplicaciones web y demostrar cómo crear interfaces interactivas que permitan a los usuarios comunicarse con sistemas de IA.
